# شجرة الأنساب العربية

[![الحالة](https://img.shields.io/badge/الحالة-قيد_التطوير-yellow.svg)]()
[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/)
[![Next.js](https://img.shields.io/badge/Next.js-14-black.svg)](https://nextjs.org/)
[![الرخصة](https://img.shields.io/badge/الرخصة-MIT-green.svg)](LICENSE)

تطبيق ويب تفاعلي يتتبع النسب العربي من إبراهيم الخليل عليه السلام حتى خاتم الأنبياء محمد صلى الله عليه وسلم وصحابته الكرام، عبر خمسة وعشرين جيلاً وثمانية وخمسين شخصية تاريخية.

---

## المميزات

- **شجرة تفاعلية** — استعراض الأجيال تدريجياً جيلاً بعد جيل
- **تسليط الضوء على الجد المشترك** — اختر حتى ستة أشخاص وستظهر المسارات الموصلة إلى جدهم المشترك
- **ثنائية اللغة** — واجهة عربية (من اليمين إلى اليسار) وإنجليزية
- **بطاقات الشخصيات** — نبذة مفصّلة عن كل شخصية مع التواريخ والسيرة
- **البحث والفلترة** — البحث بالاسم أو التصفية حسب الفئة
- **تمييز بالألوان** — لكل فئة لون خاص بها:
  - **الأخضر** — الأنبياء
  - **الأزرق** — الصحابة وأمهات المؤمنين
  - **الأحمر** — القادة والأجداد
  - **العنبري** — الشعراء
  - **البنفسجي** — العلماء

## تشغيل التطبيق

### المتطلبات

- Python 3.11 أو أحدث
- Node.js 18 أو أحدث
- uv أو pip

### الخطوات

**استنساخ المستودع:**
```bash
git clone https://github.com/youssef-abbih/family-tree-app.git
cd family-tree-app
```

**تشغيل الخادم الخلفي (الطرفية الأولى):**
```bash
cd backend
uv sync          # أو: pip install fastapi uvicorn python-dotenv
uvicorn app.main:app --reload --port 8000
```

**تشغيل الواجهة الأمامية (الطرفية الثانية):**
```bash
cd frontend
npm install
npm run dev
```

**فتح التطبيق في المتصفح:**
- التطبيق: `http://localhost:8080`
- توثيق الواجهة البرمجية: `http://localhost:8000/docs`

## واجهة برمجية (API)

| المسار | الوصف |
|--------|--------|
| `GET /api/persons` | جميع الشخصيات |
| `GET /api/persons/{id}` | شخصية بعينها |
| `GET /api/generations/{n}` | أبناء الجيل رقم n |
| `GET /api/search?q=` | بحث بالاسم |
| `GET /api/filter?type=` | تصفية حسب الفئة |
| `GET /api/stats` | إحصاءات عامة |
| `POST /api/lca` | إيجاد الجد المشترك الأدنى |
